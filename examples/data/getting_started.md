# Getting started with Orbit Notes

Orbit Notes is a note taking app for Windows, macOS, Linux, iOS and Android.
To create an account, open the app and choose Sign up with your email address. You will receive a confirmation link that stays valid for 24 hours.
Every new account starts with a default notebook called Inbox. Notes you create without picking a notebook land there.
You can import notes from Markdown files, plain text files and Evernote exports. Open Settings, choose Import and select the files or the export archive.
Notebooks can be nested up to five levels deep. Drag a notebook onto another one to nest it.
