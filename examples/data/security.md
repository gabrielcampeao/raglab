# Security and privacy

All notes are encrypted in transit with TLS 1.3 and at rest with AES 256.
Plus and Team accounts can turn on end to end encryption for individual notebooks. When it is on, Orbit Notes servers cannot read the content of those notebooks.
If you lose the recovery key for an encrypted notebook, support cannot recover its content.
Two factor authentication is available on every plan. Turn it on in Settings under Account security using an authenticator app or a hardware security key.
Orbit Notes never sells personal data and does not use note content to train machine learning models.
Data is stored in data centers in Frankfurt and Virginia. Team admins can choose the region when creating the workspace.
